# Reposition HAD as an open governance protocol

## What will change
- Rewrite the hero in English, Portuguese, and Spanish around measurable autonomy and selective governance.
- Add “How it works” directly after the hero, with three protocol steps, a typed response example, and a clear early-access label.
- Add a visible L0–L5 autonomy section using the existing autonomy data and translated labels.
- Replace the hero’s main download action with an email-based API access request; retain the Starter Kit as the secondary action.
- Add “How it works” to desktop and mobile navigation.

## Data and behavior
- Store API access requests in a new protected waitlist table in Lovable Cloud.
- Validate email, prevent duplicate entries, and show localized success or error feedback.
- Keep the protocol presented as forthcoming; no live endpoint or interactive API call will be implied.
